How it works

xn+1 = 4 xn(1 − xn)

u = 2⁄π arcsin √x

  1. Seed. The seed text is hashed into two starting values, x₀ and y₀, between 0 and 1. Change a single letter and both start somewhere else.
  2. Stir. Each map is iterated several times between draws. At r = 4 the logistic map doubles any error on average every step, so after a few dozen steps the starting digits are completely forgotten.
  3. Flatten. The map spends most of its time near 0 and 1. The arcsine change of variables turns its values into a uniform u, so no digit is favoured.
  4. Extract. Bits from deep inside u, the most sensitive ones, are taken from both maps and combined with XOR. Values that would favour part of the alphabet are thrown away and redrawn, so every character has the same chance.

This is a demonstration of chaos, not a cryptographic generator. The same seed always gives the same sequence, and floating-point arithmetic only approximates true chaos. For passwords, use your password manager.
